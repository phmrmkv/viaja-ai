# Caravan

Site demonstrativo de viagens (estudo da Digital House), modernizado com Astro e Tailwind 4.
No ar em https://caravan.libertycondominio.online. Projeto de estudo: contatos, planos, eventos e formulários são fictícios e nada é enviado.

- `npm install`, `npm run dev`, `npm run check`, `npm run build` (o sharp pode dar segfault no Node 26: repita o build).
- Versão original em Bootstrap 4 guardada em `referencias/original/` (fora do build).
